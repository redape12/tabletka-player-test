ТАБЛЭТКА — тестовая PWA

Загрузи ВСЕ файлы из этой папки в корень отдельного публичного репозитория GitHub (например, tabletka-player-test), затем включи Settings → Pages → Deploy from a branch → main / root.

На Samsung открой опубликованный HTTPS-адрес в Chrome → меню ⋮ → Установить приложение / Добавить на главный экран.

Это тестовый плеер: MP3 выбираются вручную с телефона, после перезапуска приложения их может потребоваться выбрать заново. Каталог Telegram не превращён в потоковый аудиоплеер.

Проверь воспроизведение при блокировке экрана и кнопки наушников. Не загружай в публичный репозиторий .env, токен бота или SQLite.
